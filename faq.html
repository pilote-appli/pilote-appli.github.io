Les questions qu'on se pose

Vous ne trouvez pas la vôtre ? Écrivez-nous depuis la page Contact.

Vos données

Où Pilote enregistre-t-il mes données ?

Dans des fichiers sur votre ordinateur, et nulle part ailleurs :

  • version Microsoft Store : C:\Users\<votre nom>\Pilote\Donnees ;
  • version téléchargée sur GitHub : le dossier Donnees à côté de l'application ;
  • Mac : ~/Library/Application Support/Pilote/Donnees.

Le chemin exact est aussi affiché dans les Paramètres de Pilote.

Désinstaller Pilote efface-t-il mes données ?

Non. Vos données restent dans leur dossier ; vous les retrouvez si vous réinstallez Pilote. Pour les supprimer, effacez ce dossier vous-même, ou utilisez Paramètres › Données & application › Effacer toutes mes données avant de désinstaller.

Comment passer sur un autre ordinateur, ou de la version GitHub à celle du Store ?

Par la sauvegarde : dans Paramètres › Sauvegarde, envoyez vos données sur une clé USB, puis, dans la nouvelle installation, restaurez-les depuis cette clé. Les deux versions ne partagent pas automatiquement leurs données.

Pilote fonctionne-t-il sans Internet ?

Oui. Sans connexion, Pilote affiche les derniers cours qu'il connaît et vous pouvez tout saisir. Internet ne sert qu'aux cours de bourse, aux mises à jour et aux connexions que vous avez choisies (Gmail, iCloud, montres).

Pilote est-il gratuit ?

Oui, sans publicité et sans compte.

Sécurité

Plusieurs personnes peuvent-elles utiliser Pilote sur le même ordinateur ?

Oui. Chaque utilisateur a ses propres données, ses réglages, son thème et, s'il le veut, son code PIN. Rien n'est partagé de l'un à l'autre.

J'ai oublié mon code PIN.

Le code PIN ne se récupère pas depuis l'application. Il empêche une autre personne d'ouvrir vos données dans Pilote sur un ordinateur partagé ; il ne les chiffre pas. Écrivez-nous depuis la page Contact : nous vous expliquerons comment le retirer.

J'ai oublié le mot de passe de mes sauvegardes.

Elles sont alors perdues. Ce mot de passe chiffre vos archives et n'est gardé nulle part, ni par Pilote ni par nous : personne ne peut les rouvrir sans lui. Vos données dans Pilote, elles, ne sont pas touchées ; faites une nouvelle sauvegarde avec un nouveau mot de passe.

Connexions et montres

Comment relier ma boîte Gmail (Actus) ?

Pilote lit votre boîte avec un mot de passe d'application de Google, pas avec votre mot de passe habituel. Il faut que la validation en deux étapes soit activée sur votre compte Google. La section Actus de Pilote vous guide pas à pas. Pilote ne fait que lire la boîte : il n'y envoie rien.

Comment relier mon agenda iCloud ?

Avec votre identifiant Apple et un mot de passe pour app, créé sur account.apple.com, dans Connexion et sécurité. Pilote écrit dans un agenda les notes et rappels que vous lui demandez, et lit vos autres agendas sans jamais les modifier.

Quelles montres Pilote sait-il lire ?
  • Garmin : avec la clé API personnelle que vous créez dans les paramètres de votre compte Garmin Connect.
  • Coros : en vous connectant à votre compte Coros sur la page de connexion que Pilote ouvre.
  • Toute autre montre : en important les fichiers .fit de vos séances.

Pilote lit vos séances, votre sommeil et votre forme du jour. Il n'écrit jamais rien dans votre compte.

Où sont gardés mes codes d'accès ?

Sur votre ordinateur, chiffrés par le système (Windows, ou le Trousseau sur Mac). Ils ne servent qu'à parler directement à Google, Apple, Garmin ou Coros depuis votre ordinateur.

Bourse

D'où viennent les cours de bourse ?

Pilote les demande sur Internet en n'envoyant que le code des titres que vous suivez, jamais vos montants ni vos quantités. Les cours sont rafraîchis toutes les minutes au plus, et peuvent avoir un léger retard sur le marché.

Puis-je importer les relevés de ma banque ?

Oui, pour le PEA, les comptes-titres et la crypto. Le fichier CSV ou Excel de votre banque donne le meilleur résultat ; le PDF marche aussi. Vous voyez les opérations lues avant de les ajouter. Si votre banque n'est pas bien reconnue, dites-le nous.
