Support

Un souci avec Pilote ?

La plupart des problèmes se règlent par une mise à jour. Si ce n'est pas le cas, Pilote prépare pour vous le message à nous envoyer.

Avant d'écrire

  1. Vérifiez que Pilote est à jour. La version du Microsoft Store se met à jour par le Store. Les autres versions le proposent d'elles-mêmes au démarrage, et dans Paramètres › Mises à jour, où se trouve aussi l'historique de chaque version.
  2. Regardez les questions fréquentes : données, sauvegardes, code PIN, montres et connexions.

Signaler un problème

Depuis Pilote

Ouvrez Paramètres › Données & application › Signaler un problème. Pilote prépare un mail avec sa version, votre système et ses derniers plantages, sans aucune de vos données. Vous voyez tout ce qu'il contient et vous le relisez avant que votre messagerie l'envoie.

Si Pilote ne s'ouvre plus, écrivez à pilote.appli+probleme@gmail.com en indiquant :

  • la version de Pilote, et d'où vous l'avez installé (Microsoft Store ou GitHub) ;
  • votre système : Windows 10, Windows 11 ou macOS ;
  • ce que vous faisiez, et le message affiché s'il y en a un.

N'envoyez jamais vos fichiers de données, ni une capture où l'on voit vos montants : nous n'en avons pas besoin.

Installer Pilote

Windows

Le plus simple est le Microsoft Store : l'application y est vérifiée par Microsoft et se met à jour toute seule. Il faut Windows 10 ou 11.

Vous pouvez aussi télécharger Pilote_Setup.exe sur la page des versions. Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur » : cliquez sur Informations complémentaires, puis Exécuter quand même.

Mac

Le tuto détaillé, avec captures, est sur la page Pilote sur Mac.

  1. Téléchargez Pilote_Mac.zip sur la page des versions (Mac à puce Apple).
  2. Ouvrez le fichier, puis glissez Pilote dans le dossier Applications.
  3. Lancez Pilote une première fois. macOS le bloque, car l'application n'est pas encore signée par Apple : fermez l'avertissement.
  4. Ouvrez Réglages Système › Confidentialité et sécurité, descendez jusqu'à Pilote et cliquez sur Ouvrir quand même. Ce n'est à faire qu'une fois.

Une idée pour Pilote ?

Le bouton Une idée ?, à côté de votre prénom sur l'accueil de Pilote, prépare un mail. Vous pouvez aussi écrire à pilote.appli+idee@gmail.com. Toutes les autres adresses sont sur la page Contact.
