Confidentialité

Politique de confidentialité

Mise à jour le 10 novembre 2026

En résumé

Pilote ne collecte aucune donnée. Il n'a ni compte, ni serveur, ni publicité, ni mesure d'audience : tout ce que vous saisissez reste sur votre ordinateur, et personne d'autre que vous n'y a accès, pas même l'auteur de l'application. Ce site non plus ne mesure pas son audience et ne dépose aucun cookie.

Où vivent vos données

Vos comptes, vos opérations, vos séances de sport, vos mesures de santé et vos réglages sont enregistrés dans des fichiers sur votre ordinateur :

  • version Microsoft Store : C:\Users\<votre nom>\Pilote\Donnees ;
  • version téléchargée sur GitHub : le dossier Donnees à côté de l'application ;
  • Mac : ~/Library/Application Support/Pilote/Donnees.

Ils ne sont envoyés nulle part. Désinstaller Pilote ne les efface pas : vous pouvez les supprimer vous-même en effaçant ce dossier.

Ce que Pilote demande à Internet

Pour afficher des informations publiques, Pilote interroge directement ces services depuis votre ordinateur :

  • Cours de bourse : Yahoo Finance et Euronext reçoivent les codes des titres dont vous suivez le cours (par exemple WPEA.PA), jamais vos montants ni vos quantités.
  • Composition des ETF : justETF, iShares et Amundi reçoivent l'identifiant (ISIN) des fonds concernés.
  • Mises à jour : la version téléchargée sur GitHub vérifie sur GitHub s'il existe une nouvelle version. La version Microsoft Store est mise à jour par le Store.

Comme pour toute page web, ces services voient l'adresse IP de votre connexion. Pilote ne leur transmet aucun identifiant ni aucune information personnelle.

Les connexions que vous choisissez

Ces fonctions sont éteintes tant que vous ne les réglez pas vous-même :

  • Actus (Gmail) : Pilote lit la boîte Gmail que vous indiquez, pour afficher vos lettres d'information. Il ne l'utilise que pour la lire et n'y envoie rien.
  • Agenda (iCloud) : Pilote écrit dans votre agenda iCloud les notes et rappels que vous lui demandez, et lit vos autres agendas pour les afficher sans les modifier. Si vous réglez la notification « Bilan de la semaine », elle contient un résumé de vos comptes, de vos dépenses et de votre poids.
  • Montres (Garmin, Coros) : Pilote lit dans votre compte Garmin Connect ou Coros vos séances, votre sommeil et votre forme du jour. Il n'y écrit rien. Les fichiers .fit que vous importez sont lus sur votre ordinateur, sans connexion.

Les codes d'accès de ces services sont chiffrés sur votre ordinateur par le système (Windows ou le Trousseau du Mac). Les échanges se font directement entre votre ordinateur et Google, Apple, Garmin ou Coros, selon leurs propres règles de confidentialité.

Sauvegardes

Si vous activez la sauvegarde, Pilote copie vos fichiers sur la clé USB ou dans le dossier que vous choisissez. Avec un mot de passe, ces archives sont chiffrées sur votre ordinateur avant d'être copiées ; ce mot de passe n'est gardé nulle part. Si le dossier choisi est synchronisé par un service en ligne (Google Drive, iCloud Drive, OneDrive), c'est ce service, et non Pilote, qui envoie les fichiers.

Signaler un problème

Le bouton « Signaler un problème » prépare un mail avec la version de Pilote, votre système et ses derniers plantages, sans aucune de vos données. Vous le relisez, et c'est votre messagerie qui l'envoie, seulement si vous le décidez. Nous utilisons ces mails pour répondre et corriger Pilote, et ne les transmettons à personne.

Contact

Pour toute question sur cette politique, écrivez à pilote.appli@gmail.com.

Le code de Pilote est public sur GitHub : chacun peut vérifier ce qu'il envoie, et à qui.
