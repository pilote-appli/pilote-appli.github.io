Pour un problème, le plus rapide est le bouton Signaler un problème dans Paramètres › Données & application : il joint ce qu'il faut pour comprendre, sans aucune de vos données. Le détail est sur la page Support.

N'envoyez jamais vos fichiers de données ni vos codes d'accès. Personne chez Pilote ne vous les demandera.
